<objective>
Stop gitleaks false positives on GSD-generated JSON manifest checksums by
replacing the fragile per-line fingerprint ignores with a durable, rule-targeted
regex allowlist in `.gitleaks.toml`.

The manifests (`.claude/gsd-file-manifest.json`,
`.claude/gsd-local-patches/backup-meta.json`) store SHA-256 file-integrity
checksums as `"path": "<64-hex>"` JSON values. gitleaks' `generic-api-key` rule
flags these as secrets. Because the files are regenerated by GSD tooling, both
the hashes and their line numbers drift — the `.gitleaksignore` fingerprints for
these files have already gone stale twice.

Purpose: One durable config change that survives manifest regeneration, keeps a
real pasted secret flaggable, and removes the stale fingerprint churn.
Output: Updated `.gitleaks.toml` and `.gitleaksignore`; verified 0 leaks.
</objective>
