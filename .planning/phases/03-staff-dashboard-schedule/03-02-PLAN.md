## Phase Goal

**As a** salon staff member, **I want to** log into a private dashboard, see the day's and week's appointments, and update each appointment's status (including marking no-shows separately), **so that** I can run the salon's schedule from one authenticated place.

<objective>
Deliver the first user-facing capability of the phase: **staff authentication**. Staff exchange email+password for a ~12h JWT, and the staff API rejects anonymous callers. Also ships the Owner-only "add staff user" endpoint (D-04) so the Owner can create the rest of the team from the dashboard. This is a vertical slice: after this plan, a staff account can log in and the auth gate is real and tested.

Purpose: DASH-05 (auth gate) + D-01/D-04 (per-staff accounts, Owner-creates-staff) at the API tier.
Output: AuthController + StaffUsersController + their DTOs/validators + a green AuthGateTests covering login, 401, and the Owner-vs-Staff role split.
</objective>
