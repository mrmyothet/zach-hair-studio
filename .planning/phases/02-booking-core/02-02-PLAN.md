## Phase Goal

**As a** client, **I want to** pick a service and book a real open slot with my chosen stylist, **so that** my appointment is confirmed and never double-booked.

> Testability prerequisite. The correctness guarantees this phase exists to prove — SC4 (DB-level double-booking) and SC5 (DST-correct datetimeoffset) — CANNOT be proven with the existing InMemory fixture (it enforces no unique indexes). This plan stands up the real-SQL-Server fixture and completes the external Resend setup the user locked in via D-12. No user-facing behavior ships here; it unblocks Plan 04.

</objective>
