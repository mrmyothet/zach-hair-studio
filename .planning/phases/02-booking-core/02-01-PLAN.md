## Phase Goal

**As a** client, **I want to** pick a service and book a real open slot with my chosen stylist, **so that** my appointment is confirmed and never double-booked.

> Vertical slice, part 1 of the phase. Lays the booking data model and the DB-level double-booking guarantee (the unique index), retires the legacy free-text `Booking` wholesale (D-14), and ships one observable end-to-end read path — `GET /api/stylists` returns the seeded team. The heavy correctness work (slot query, retry loop, concurrency proof) rides on the schema this plan creates.

<objective>
Create the booking domain model (Stylist, availability, Appointment + AppointmentSlot with the unfiltered unique index), seed stylists and default working hours via HasData, expose a thin read-only `StylistsController`, wire the `Salon:IanaTimeZoneId` config, retire the legacy `Booking` entity and every consumer of it (API + Admin), and apply the whole thing as one BLOCKING EF Core migration.

Purpose: Establish the schema and the database-enforced double-booking guarantee (SC4) that all later plans depend on, and remove the free-text booking path so nothing half-migrated remains (D-14).
Output: Five new tables (one dropped), a seeded stylist list endpoint, the `AddBookingCore` migration applied to LocalDB, and the salon timezone configured.
</objective>
