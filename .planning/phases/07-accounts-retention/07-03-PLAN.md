## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Account cancel/reschedule API | Untrusted appointment id + StartsAt/StylistId; Bearer JWT asserted Client role |
| Account API → AppointmentsService / DB | Trusted after ownership + transition + until-start checks; writes Appointment + AppointmentSlot |
| Client self-service vs Staff schedule | Separate routes; staff keep dashboard status PATCH; clients must not elevate into staff transitions (Completed/NoShow) via account APIs |
| Concurrent bookers → unique index | Unfiltered (StylistId, SlotStart) is the double-booking guarantee across guest book + reschedule |
