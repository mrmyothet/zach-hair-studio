## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staff dashboard → AppointmentsService.UpdateStatusAsync | Trusted staff JWT Completes appointments; earn must not double-credit |
| Browser → Orders checkout/quote | Untrusted RedeemPoints and any money-shaped JSON |
| LoyaltyService → LoyaltyLedger | Append-only deltas; balance is derived sum |
| Browser → Account loyalty GET | Client JWT only; balance is not a secret but must not leak other users |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-20 | Tampering | CheckoutRequestDto / OrdersService.CreateCheckoutAsync | critical | mitigate | Accept RedeemPoints only; recompute merchandise from Product.Price; server dollars = floor(pts/10)*RedeemBlockDollars capped at subtotal; ignore client dollar-off JSON; payment session uses discounted TotalAmount |
| T-07-21 | Tampering | Loyalty quote endpoint | high | mitigate | Quote recomputes catalog + LoyaltyRates server-side; Continue to Payment recomputes again inside stock transaction — preview cannot lock a forged discount |
| T-07-22 | Tampering | Double-spend / over-redeem | high | mitigate | Balance check + Redeem ledger row inside CreateExecutionStrategy transaction with stock decrement; reject when RedeemPoints &gt; balance or not multiple of 10 |
| T-07-23 | Tampering | Double-earn on Completed | high | mitigate | Existence check + unique filtered index on Earn AppointmentId before insert (Pitfall 3) |
| T-07-24 | Elevation of Privilege | GET /api/account/loyalty | medium | mitigate | Authorize Roles=Client; balance filtered by NameIdentifier only |
| T-07-25 | Information Disclosure | Cross-client ledger | medium | mitigate | All ledger reads/writes scoped to authenticated ClientUserId; earn only for appointment owner ClientUserId |
| T-07-26 | Repudiation | LoyaltyLedger | low | accept | Append-only rows with CreatedAtUtc + Reason provide audit trail sufficient for MVP; no mutable balance column |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages — EF/Identity/FluentValidation/Next already in-repo (Package Legitimacy N/A) |
